1) เข้า GitHub repository:
   sayampreecha-ux/-ai-local-government-assistant

2) กด Add file > Upload files

3) อัปโหลดเฉพาะไฟล์ app.js ในชุดนี้
   ห้ามอัปโหลดไฟล์ ZIP ทั้งก้อน

4) เลือก Replace existing file

5) Commit message:
   Enable 20 free prompts safely

6) กด Commit changes

7) รอ GitHub Pages อัปเดต แล้วเปิดเว็บไซต์
   กด Ctrl + F5
