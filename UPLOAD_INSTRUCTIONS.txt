วิธีอัปโหลดครั้งเดียว
1. แตก ZIP นี้
2. เปิดโฟลเดอร์ GovPrompt-GitHub-One-Time-Fix
3. เลือกไฟล์ทั้งหมดภายในโฟลเดอร์พร้อมกัน
4. GitHub: Add file > Upload files
5. Commit directly to main > Commit changes
6. รอ 1–3 นาที แล้วกด Ctrl+F5

แพ็กเกจนี้เป็น Public-only:
ไม่มี Prompt Master, API, Supabase, .env, Secret หรือรายงานภายใน
