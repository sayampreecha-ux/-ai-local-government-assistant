วิธีกู้เว็บไซต์ GitHub Pages

1. เปิด Repository:
   sayampreecha-ux/-ai-local-government-assistant

2. กด Add file > Upload files

3. แตกไฟล์ ZIP นี้ก่อน แล้วลาก “ไฟล์ภายใน” ทั้งหมดขึ้น Repository ระดับบนสุด
   ห้ามลากโฟลเดอร์ govprompt-github-pages-recovery ขึ้นไปทั้งโฟลเดอร์

4. เมื่อ GitHub แจ้งว่าไฟล์มีอยู่แล้ว ให้ยืนยัน Replace/Commit

5. Commit message:
   Restore GovPrompt Thailand website

6. เปิด Settings > Pages และตรวจว่า:
   Branch = main
   Folder = /(root)

7. เปิดเว็บไซต์แล้วกด Ctrl + F5:
   https://sayampreecha-ux.github.io/-ai-local-government-assistant/

หมายเหตุ:
- index.html ได้แก้ path เป็นแบบสัมพัทธ์สำหรับ GitHub Pages แล้ว
- ปุ่ม “เริ่มใช้ฟรีทันที” เชื่อมไปยังส่วนเครื่องมือ
- ห้ามอัปโหลด Owner Master, .env หรือข้อมูลลับ
