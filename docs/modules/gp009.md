# GP009 — Public Relations Copilot

GP009 is a standalone deterministic communications module over the six Sprint 1 Core
services. GP002, GP003, GP004, GP005, GP007, and GP008 are injected through stable
review interfaces; existing modules remain unchanged. Startup idempotently registers
prompt `2.0.0`, a 25-stage workflow, six templates, seven controlled knowledge
references, and deny-by-default communications policies.

The pipeline creates government news, press content, Facebook captions, social media
plans, infographic panels, poster layout, image metadata, eight accessibility checks,
a nine-control communication checklist, approval workflow, and publication package.
Missing communications, PDPA, or required executive approval returns
`approval_required` before prompt resolution and emits an audit event.

Templates are ข่าวประชาสัมพันธ์, One Page, Infographic, Facebook Caption, Press
Release, and Executive Summary. Outputs support Markdown, accessible HTML, JSON,
API response, and audit log. Knowledge covers government PR rules, CI, PDPA, Digital
Government, DLA directives, government communication, and social-media guidance.
Production adapters must resolve `govprompt://` pointers to current official sources.

Run `node demo/gp009-demo.js` for an executable publication package and diagnostics.
