# GP010 — Meeting Copilot

GP010 is a standalone, deterministic meeting-management module built on the six
Sprint 1 Core services. It uses ContextManager for meeting state, TransactionRouter
for routing, PromptRegistry for the versioned prompt and workflow, KnowledgeRegistry
for controlled references, GovernanceLayer for role and source authorization, and
Observability for traces, metrics, audit events, and diagnostics.

The module accepts injected GP001–GP009 instances through stable `execute()`
interfaces. Cross-module reviews are opt-in through `linkedReviews`; GP010 does not
change or couple itself to the internal implementation of an earlier module.

## Workflow

The 21-stage workflow validates the request, routes it, retrieves and authorizes
knowledge, runs optional linked reviews, builds the agenda, verifies attendance,
generates minutes and resolutions, derives action items and reminders, constructs a
decision register, validates the final package, and records metrics and an audit
trail. Dates are evaluated against the required `asOfDate`, keeping overdue and
reminder results reproducible.

Supported features include agenda building, minutes generation, resolution drafting,
attendance validation, action items, follow-up tracking, meeting and executive
summaries, a decision register, reminder package, audit trail, and export package.

## Registration and outputs

Startup idempotently registers prompt `GP010` version `2.0.0`, its workflow, six
templates, five knowledge records, and deny-by-default policies. The templates are
Agenda, Minutes, Resolution, Meeting Summary, Executive Summary, and Action Tracker.
Outputs are available as Markdown, accessible HTML, JSON, API response, and audit log.

Knowledge records cover meeting procedure, local council work, official
correspondence, DLA directives, and related law. The bundled `govprompt://` records
are deterministic catalog entries; a production adapter should resolve them against
current authoritative publications.

Run `node demo/gp010-demo.js` to generate a complete API response and print Core
diagnostics.
