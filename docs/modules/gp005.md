# GP005 — Budget Copilot

## Architecture

GP005 is a standalone module over the six Sprint 1 Core services. GP002 legal,
GP003 procurement, and GP004 finance reviews are injected and invoked only when the
request supplies their explicit review inputs. No existing module is modified.
Startup idempotently registers prompt `2.0.0`, a 23-stage workflow, eight templates,
twelve controlled knowledge references, and deny-by-default RBAC policies.

## Deterministic analysis

The engines cover availability, sufficiency, classification, annual appropriation
and ordinance validity, transfers and amendments, reservations, reserve funds,
multi-year commitments, development/strategic plan consistency, central budget,
timeline, execution analytics, fiscal risk, and a thirteen-control compliance check.
Cross-module results are embedded as immutable evidence and GP005 restores itself as
the active ContextManager module after linked reviews.

## Outputs and knowledge

Budget Opinion, Sufficiency Report, Transfer Analysis, Compliance Report, Fiscal Risk
Report, Executive Summary, One Page, and Decision Memo support Markdown, JSON,
audit-log, executive-report, and API-response formats. Knowledge covers all twelve
requested regulation, ordinance, plan, transfer, reserve, and audit source classes.
`govprompt://` references must be resolved to current authoritative corpora by a
production adapter.

## Demo

Run `node demo/gp005-demo.js` to initialize Core plus GP002–GP004 and produce a
deterministic API budget opinion with diagnostics.
