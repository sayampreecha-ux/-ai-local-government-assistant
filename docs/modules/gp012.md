# GP012 — Knowledge Search Copilot

GP012 is a standalone deterministic search layer over ContextManager,
TransactionRouter, PromptRegistry, KnowledgeRegistry, GovernanceLayer, and
Observability. GP001–GP011 are injected through stable `execute()` interfaces and
are called only for explicitly supplied `linkedReviews`; existing modules remain
unchanged.

The module indexes authorized Knowledge Registry versions together with versioned
Prompt Registry definitions. It applies source and effective-date filtering,
canonical version resolution, Unicode lexical and semantic matching, authority and
confidence ranking, duplicate and conflict detection, related-document discovery,
and validated citations. Stable sorting and explicit `asOfDate` make identical
inputs and registry snapshots produce identical analysis.

Startup idempotently registers prompt `GP012` version `2.0.0`, its 20-stage workflow,
six templates, ten search connectors, and deny-by-default search policies. Knowledge
connectors cover laws, regulations, directives, Cabinet resolutions, judgments,
legal inquiries, manuals, FAQs, the internal Knowledge Registry, and Prompt Registry.
Deployments must resolve `govprompt://` pointers to current authoritative sources.

Templates include Unified Search, Legal Research, Citation Report, Conflict Report,
Executive Summary, and API Search. Outputs support Markdown, accessible HTML, JSON,
API response, and audit log. The API response includes ranked results, citations,
total count, workflow metadata, and traceable result IDs.

Run `node demo/gp012-demo.js` for a complete search across the initialized GP001–GP012
runtime and Core diagnostics.
