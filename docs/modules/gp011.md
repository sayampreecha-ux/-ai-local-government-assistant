# GP011 — PDPA Copilot

GP011 is a standalone deterministic privacy-compliance module over ContextManager,
TransactionRouter, PromptRegistry, KnowledgeRegistry, GovernanceLayer, and
Observability. GP001–GP010 are injected through stable `execute()` interfaces and
invoked only when a request supplies the corresponding `linkedReviews` input; no
existing module is changed.

The workflow detects national IDs, email addresses, phone numbers, health terms, and
biometric terms; classifies sensitive data; masks structured records recursively;
validates lawful basis and purpose-bound consent; assesses disclosure, retention,
disposal, domestic and cross-border sharing; calculates a deterministic 0–100 risk
score; applies a ten-control compliance checklist; and produces approval, audit, and
compliance evidence. Sensitive processing requires Data Protection Officer approval,
and high-risk processing also requires supervisor approval.

Startup idempotently registers prompt `GP011` version `2.0.0`, a 21-stage workflow,
six templates, six controlled knowledge records, and deny-by-default privacy
policies. Templates cover PDPA Assessment, Masking Report, Consent Review, Disclosure
Review, Compliance Report, and Executive Summary. Outputs support Markdown,
accessible HTML, JSON, API response, and audit log.

The knowledge catalog covers the PDPA, PDPC notices, government guidance, official
correspondence rules, Digital Government guidance, and Cybersecurity guidance.
`govprompt://` entries are deterministic catalog pointers; deployments must resolve
them to current authoritative publications and effective versions.

Run `node demo/gp011-demo.js` to execute a complete compliance assessment and print
Core diagnostics.
