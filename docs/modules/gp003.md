# GP003 — Procurement Copilot

## Architecture

GP003 is an isolated module built on the six public Sprint 1 Core services. It does
not modify GP001, GP002, or Core. Startup idempotently registers prompt `2.0.0`, the
workflow definition, six report templates, seven controlled procurement knowledge
sources, and role-based policies.

The deterministic pipeline validates input, routes to GP003, retrieves and
authorizes knowledge, reviews TOR requirements, detects specification lock,
evaluates competition and vendor qualifications, analyzes pricing, recommends a
procurement method and e-GP sequence, assesses contract risk, builds an audit
checklist, authorizes the prompt, validates output, updates ContextManager, and emits
correlated metrics and audit events.

## Engines

- TOR Engine scores clarity and measurability and detects brand, restrictive-language,
  and single-vendor locks.
- Competition Engine scores fairness using TOR restrictions, vendor-pool size, and
  submission window.
- Vendor Engine compares every vendor against explicit qualification criteria.
- Pricing Engine calculates range, mean, budget variance, reasonableness, and outliers.
- Procurement Engine recommends a method from budget and competition conditions and
  returns the nine-stage e-GP workflow.
- Risk Engine combines TOR, competition, vendor, pricing, method, and contract risks.
- Compliance Engine returns a nine-item audit checklist and overall compliance state.
- Output Engine supports JSON, Markdown, audit-log, and API-response envelopes.

## Registered knowledge

The module registers controlled references for the Procurement Act, Ministry of
Finance Regulation, Comptroller General's Department circulars, legal rulings,
related court precedents, NACC guidance, and State Audit Office guidance. The
`govprompt://` values are metadata references; a production adapter must resolve
them to current authoritative text.

## Templates

TOR Review, Procurement Opinion, Procurement Checklist, Risk Report, Executive
Summary, and One Page Procurement Brief share one validated analysis model.

## Demo

Run `node demo/gp003-demo.js`. The demo creates an isolated Core runtime, performs a
procurement opinion, and prints the API response plus diagnostics.
