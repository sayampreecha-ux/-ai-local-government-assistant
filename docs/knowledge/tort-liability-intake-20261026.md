สถานะ: DRAFT; ยังไม่เชื่อม runtime, ไม่ใช่ความเห็นทางกฎหมาย, ไม่มีข้อสรุปสัดส่วนความรับผิด

## วัตถุประสงค์
รวบรวมประเด็นตรวจสอบข้อเท็จจริงความรับผิดทางละเมิดของเจ้าหน้าที่สำหรับ อบจ./เทศบาล/อบต. โดยใช้ฐานกฎหมายจริงอย่างมีหลักฐาน และส่งต่อ AI ฟรีให้ร่างเอกสารเพื่อให้เจ้าหน้าที่ตรวจทานเท่านั้น ไม่มีการตัดสินความรับผิดอัตโนมัติ

## ชุดความรู้ 10 หมวด
1. พ.ร.บ.ความรับผิดทางละเมิดของเจ้าหน้าที่ พ.ศ. 2539 — ตรวจต้นฉบับและสถานะการแก้ไขก่อนอ้าง
2. ระเบียบสำนักนายกรัฐมนตรีว่าด้วยหลักเกณฑ์การปฏิบัติเกี่ยวกับความรับผิดทางละเมิดของเจ้าหน้าที่ และฉบับแก้ไข — ตรวจอำนาจ/กรรมการ/ขั้นตอน
3. หนังสือเวียนกระทรวงการคลัง ว 56, ว 66, ว 75, ว 217 และฉบับเพิ่มเติม/ยกเลิก
4. แนวสอบข้อเท็จจริงจากภาพผู้ใช้ 7 ภาพ (หนึ่งภาพอุบัติเหตุซ้ำ); เป็น secondary procedural material ไม่ใช่ตัวบท
5. ขั้นตอนตั้งแต่รับรายงานเหตุจนสรุปสำนวน
6. การตรวจองค์ประกอบการกระทำละเมิด จงใจ/ประมาทเลินเล่ออย่างร้ายแรง และเหตุสัมพันธ์
7. สัดส่วนความรับผิด: พิจารณาความบกพร่องของหน่วยงาน ความเป็นธรรม บทบาทรายบุคคล ตามแนวทางที่ใช้บังคับ
8. การชดใช้แก่บุคคลภายนอก ประกันภัย รถราชการ การซ่อม และสิทธิไล่เบี้ย
9. อายุความ การออกคำสั่ง การติดตาม และสิทธิโต้แย้งตามกฎหมายเฉพาะเรื่อง
10. แบบเอกสาร ได้แก่ รายงานเหตุ คำสั่งกรรมการ บัญชีหลักฐาน คำถามพยาน รายงานความเห็น ตารางส่วนรับผิด หนังสือแจ้ง และร่างคำสั่งเรียกชดใช้ตามเงื่อนไข

## Case checklist — รถราชการชนคู่กรณี
- ประเภทรถ ทะเบียน วันเวลา สถานที่ และทรัพย์สินที่เสียหาย
- แบบขอใช้รถ คำสั่งหรือหน้าที่ผู้ขับ ผู้ควบคุม และวัตถุประสงค์เดินทาง
- บันทึกตำรวจ พยาน ภาพถ่าย CCTV ผังเหตุ สภาพถนนและรถ
- ความเสียหายรถสองฝ่าย รายงานซ่อม/ประเมินราคา ประกันภัยและสิทธิเรียกร้อง
- การเชื่อมโยงกับการปฏิบัติหน้าที่ พฤติการณ์ผู้ขับ และประเด็นจงใจ/ประมาทร้ายแรง
- ความบกพร่องของระบบงานและส่วนเกี่ยวข้องของบุคคลอื่น
- ขั้นตอนซ่อมรถและพัสดุแยกจากการกำหนดความรับผิด (ต้องตรวจฐานกฎหมาย)
- อายุความ: ห้ามคิดจากวันเกิดเหตุอย่างเดียว

- ACTION: Identity → Permission → Tool → Scope → Runtime Check → Approval → Execution → Audit → Kill Switch
