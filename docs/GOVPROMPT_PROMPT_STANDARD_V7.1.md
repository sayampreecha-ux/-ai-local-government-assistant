# GovPrompt Prompt Standard v7.1

สถานะ: Development / additive hardening layer

## เป้าหมาย
ทำให้ Prompt ของ GovPrompt ให้ผลลัพธ์สม่ำเสมอขึ้นเมื่อใช้กับ AI ต่างบัญชี/ต่างโมเดล โดยเฉพาะงานราชการที่มีผลต่อสิทธิ เงิน อำนาจ พัสดุ บุคคล วินัย และกฎหมาย โดยไม่รื้อ Prompt Catalogue เดิม 222 รายการ

## Quality Gates
1. Decision Gate — ข้อสรุป 4 สถานะ: ได้ / ไม่ได้ / ได้โดยมีเงื่อนไข / หลักฐานยังไม่พอที่จะฟันธง
2. Multi-condition Gate — ห้ามฟันธงจากการผ่านเงื่อนไขเพียงข้อเดียว
3. Legal Version Gate — ตรวจวันมีผล แก้ไข ยกเลิก และบทเฉพาะกาล
4. Evidence Gate — Official Source First และใช้ลำดับน้ำหนักหลักฐาน
5. Risk Gate — LOW / MEDIUM / HIGH; งาน HIGH ต้องตรวจ Official Source + Freshness + Multi-condition
6. Output Validation — ตรวจข้อสรุปกับข้อเท็จจริง ฐานอำนาจ เงื่อนไข ข้อยกเว้น และ PDPA ก่อนส่ง

## Golden Regression Cases ชุดเริ่มต้น
- บรรจุ 1 ม.ค. 2569 มีสิทธิรับโบนัสหรือไม่
- บรรจุครบ 8 เดือนมีสิทธิรับโบนัสทันทีหรือไม่
- ค่าทำปกเอกสารเบิกได้หรือไม่
- TOR ระบุยี่ห้อได้หรือไม่
- e-bidding ไม่มีผู้ยื่นข้อเสนอต้องดำเนินการอย่างไร
- เงินบำรุง รพ.สต. ใช้จ่ายโครงการได้หรือไม่
- เดินทางไปราชการใช้แท็กซี่เบิกได้หรือไม่
- การมอบอำนาจด้านเงินบำรุงทำได้เพียงใด
- การจัดซื้อวงเงินสูงต้องตรวจเงื่อนไขใดก่อน
- หลักเกณฑ์เก่าและใหม่ขัดกันควรใช้อะไร

## Acceptance Criteria
- ไม่สร้างเลขมาตรา/เลขหนังสือ/วันที่/แหล่งอ้างอิงขึ้นเอง
- คำถามหลายเงื่อนไขต้องไม่สรุปจากเงื่อนไขเดียว
- งาน HIGH ที่ยืนยันข้อมูลปัจจุบันไม่ได้ต้องแสดง uncertainty
- เอกสารเก่า/ใหม่ขัดกันต้องมี effective-date check
- Prompt เดิมยังอยู่ครบ และ v7.1 เป็นชั้นเสริม
- Golden cases ต้องได้ decision state และเหตุผลหลักสอดคล้องกันในการทดสอบซ้ำ

## Integration
ใช้ `applyPromptStandard(basePrompt, { question })` จาก `lib/prompt-standard-v7.1.mjs` หลังประกอบ Prompt เดิมและก่อนส่งออกให้ผู้ใช้/AI ปลายทาง
