TRUST & TRANSPARENCY

ความโปร่งใส ความปลอดภัยของข้อมูล และข้อจำกัดการใช้งาน

GovPrompt เป็นเครื่องมือช่วยค้น วิเคราะห์ และร่างงานราชการ ผู้ใช้ยังต้องตรวจสอบข้อเท็จจริง กฎหมาย เอกสารอ้างอิง และใช้ดุลพินิจก่อนนำผลลัพธ์ไปใช้จริง

สถานะของโครงการ

GovPrompt Thailand อยู่ในฐานะเครื่องมือทดลองและโครงการพัฒนาเพื่อช่วยงานราชการ (Internal Pilot) ไม่ใช่ระบบที่ใช้แทนระบบราชการทางการ ระบบสารบรรณ ระบบการเงิน ระบบพัสดุ หรือกระบวนการอนุมัติของหน่วยงาน

การนำ GovPrompt ไปใช้ในหน่วยงานใด ต้องเป็นไปตามอำนาจหน้าที่ นโยบายความมั่นคงปลอดภัยสารสนเทศ การคุ้มครองข้อมูลส่วนบุคคล และการอนุมัติของหน่วยงานนั้น ๆ

ชื่อ GovPrompt Thailand และเนื้อหาบนเว็บไซต์ไม่ควรถูกตีความว่าเป็นคำสั่ง คำวินิจฉัย หรือการรับรองอย่างเป็นทางการของหน่วยงานรัฐ เว้นแต่จะมีเอกสารหรือประกาศของหน่วยงานนั้นรองรับโดยชัดแจ้ง

⚠️ ก่อนพิมพ์หรือแนบเอกสาร

  • ห้ามใส่ข้อมูลลับของราชการ รหัสผ่าน กุญแจ API หรือข้อมูลความมั่นคง
  • หลีกเลี่ยงข้อมูลส่วนบุคคลที่ไม่จำเป็น เช่น เลขบัตรประชาชน เลขบัญชี ที่อยู่ เบอร์โทรศัพท์ หรือข้อมูลสุขภาพ
  • หากจำเป็นต้องใช้เอกสารจริง ควรปกปิดหรือลบข้อมูลที่ระบุตัวบุคคลได้ก่อน
  • ไม่ควรใช้ผลลัพธ์ AI เป็นคำวินิจฉัยหรือคำสั่งทางราชการโดยอัตโนมัติ

GovPrompt ทำอะไร

AI Copilotงานราชการไทย

ช่วยจัดโครงคำถาม ค้นประเด็น วิเคราะห์เบื้องต้น ตรวจความครบถ้วน และสร้างร่างงาน เพื่อให้เจ้าหน้าที่ทำงานได้เร็วขึ้น แต่ไม่ได้แทนที่ผู้มีอำนาจ หน่วยงานเจ้าของกฎหมาย หรือการตรวจสอบจากเอกสารต้นฉบับ

ข้อมูลถูกส่งไปที่ใดเมื่อค้นข้อมูลราชการสด

เมื่อใช้ฟังก์ชันค้นข้อมูลราชการสด ระบบจะใช้ Privacy Guard ปกปิดข้อมูลเสี่ยงที่ตรวจพบก่อนส่งคำค้นออกจากหน้าเว็บ จากนั้นคำค้นที่ผ่านการตรวจจะถูกส่งไปยัง Cloudflare Worker ของโครงการ และ Worker จะส่งคำค้นต่อไปยังผู้ให้บริการค้นเว็บ Tavily เพื่อค้นเฉพาะโดเมนราชการที่กำหนดไว้

  • Worker มีการตรวจข้อมูลเสี่ยงซ้ำอีกชั้น และอาจปฏิเสธคำค้นที่ยังมีตัวระบุหรือข้อมูลลับที่ตรวจพบ
  • โค้ด Worker ไม่บันทึกข้อความคำค้นลง application log โดยตรง แต่บันทึกเฉพาะ metadata ที่จำเป็นต่อการตรวจสอบระบบ เช่น request ID ความยาวคำค้น จำนวนแหล่ง และระยะเวลาการทำงาน
  • ผลตอบกลับของ Worker ไม่ส่งข้อความคำค้นกลับมาใน response เพื่อลดการกระจายข้อมูลโดยไม่จำเป็น
  • การค้นภายนอกยังถือเป็นการประมวลผลโดยบริการภายนอก จึงไม่ควรใส่ข้อมูลลับหรือข้อมูลส่วนบุคคลจริงที่ไม่จำเป็น แม้ระบบจะมีตัวกรอง

หลักการใช้ข้อมูลอย่างปลอดภัย

  • Data minimization: ใส่เฉพาะข้อมูลเท่าที่จำเป็นต่อคำถาม
  • Anonymization: ใช้ชื่อสมมติหรือปิดบังตัวระบุบุคคลเมื่อทำได้
  • Defense in depth: ตรวจข้อมูลเสี่ยงทั้งก่อนออกจาก browser และอีกครั้งที่ Worker
  • Fail closed: หากตรวจพบข้อมูลเสี่ยงสูง ระบบควรหยุดการค้นภายนอกแทนการส่งข้อมูลต่อ
  • Human review: ให้เจ้าหน้าที่ตรวจผลลัพธ์ก่อนใช้ทุกครั้ง
  • Source verification: ตรวจข้อความกับกฎหมาย ระเบียบ หนังสือสั่งการ และแหล่งทางการฉบับปัจจุบัน

ความรับผิดชอบและข้อจำกัด

AI อาจตอบผิด ตีความคลาดเคลื่อน หรืออ้างข้อมูลที่ล้าสมัยได้ โดยเฉพาะงานกฎหมาย การเงิน พัสดุ บุคคล และงานที่มีผลต่อสิทธิของประชาชน จึงต้องตรวจสอบแหล่งอ้างอิงและเงื่อนไขเฉพาะกรณีก่อนดำเนินการจริง

GovPrompt มีวัตถุประสงค์เพื่อช่วยงาน ไม่ใช่ระบบอนุมัติอัตโนมัติ และไม่ควรใช้เป็นช่องทางเก็บรักษาเอกสารลับหรือฐานข้อมูลส่วนบุคคลของหน่วยงาน
