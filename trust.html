GovPrompt Thailandประกาศความเป็นส่วนตัว

TRUST & TRANSPARENCY · PUBLIC BETA

ความโปร่งใสและความปลอดภัย

GovPrompt เป็น AI Copilot ช่วยงานราชการ ไม่ใช่ระบบอนุมัติหรือคำวินิจฉัยอย่างเป็นทางการของหน่วยงานรัฐ

สถานะโครงการ

Public Beta — เปิดใช้ฟรี เพื่อให้เจ้าหน้าที่ภาครัฐและผู้สนใจทดลองใช้กับงานทั่วไป ผู้ใช้ต้องตรวจผลลัพธ์และปฏิบัติตามนโยบาย/อำนาจหน้าที่ของหน่วยงานตนเองก่อนใช้จริง

ก่อนพิมพ์หรือแนบเอกสาร

อย่าใส่ข้อมูลลับ รหัสผ่าน กุญแจระบบ ข้อมูลสุขภาพ ข้อมูลอ่อนไหว เลขบัตรประชาชน เลขบัญชี หรือข้อมูลส่วนบุคคลจริงที่ไม่จำเป็น หากจำเป็นต้องอ้างกรณีจริงให้ anonymize/redact ก่อน

Data Flow ที่หน้า Home

ผู้ใช้ → Privacy Gate → Intent/Prompt Engine และเฉพาะงานที่ต้องตรวจข้อมูลปัจจุบันจึงไป Official Search → Cloudflare Worker → ผู้ให้บริการค้นเว็บภายนอก → แหล่งราชการ ก่อนนำหลักฐานกลับมาประกอบ Prompt

Privacy Guard ทำงานก่อน routing/search/prompt generation และ Worker มีการตรวจความเสี่ยงซ้ำอีกชั้น การตรวจอัตโนมัติช่วยลดความเสี่ยงแต่ไม่แทนการปกปิดข้อมูลโดยผู้ใช้

ChatGPT / Gemini Handoff

GovPrompt ไม่เชื่อมบัญชีและไม่ส่ง Prompt หรือไฟล์ไปยัง ChatGPT/Gemini อัตโนมัติ ปุ่มเปิดบริการภายนอกทำหน้าที่คัดลอก Prompt ที่ผ่าน Privacy Guard และเปิดเว็บไซต์ปลายทาง ผู้ใช้เป็นผู้วางหรือแนบข้อมูลด้วยตนเอง

การเก็บและการติดตาม

โครงการยึดหลักไม่เก็บ raw prompt เป็นคลังส่วนกลางจาก workflow หน้า Home และ Public Beta ไม่ฝัง third-party visitor counter, advertising pixel หรือ behavioral tracking บนหน้า Home หากมีการเพิ่ม telemetry ในอนาคตต้องออกแบบแบบ data-minimized และอัปเดต Privacy Notice ก่อนเปิดใช้

มาตรการที่ใช้

  • Privacy Gate ก่อนประมวลผลและการส่งออก
  • Redaction ตัวระบุทั่วไปและ hard block สำหรับ credential/private key/ข้อมูลลับที่ตรวจพบ
  • Official-source allowlist, freshness/evidence gates และ Human Review
  • Worker จำกัด origin, method, request size, rate limit, no-query-echo และลด logging
  • Prompt Standard ป้องกันการฟันธงเมื่อหลักฐานหรือเงื่อนไขไม่ครบ

ข้อจำกัดที่ต้องรู้

Regex/DLP, AI และ search provider ไม่สามารถรับประกันความถูกต้องหรือการตรวจจับข้อมูลเสี่ยงได้ 100% งานกฎหมาย การเงิน พัสดุ บุคคล วินัย หรือสิทธิประชาชนต้องตรวจต้นฉบับและผู้มีอำนาจก่อนดำเนินการ
