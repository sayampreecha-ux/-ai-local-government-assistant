PRIVACY NOTICE · INTERNAL PILOT

ประกาศความเป็นส่วนตัวสำหรับ GovPrompt Thailand

ฉบับสำหรับการทดลองใช้ภายใน เพื่ออธิบายข้อมูลที่เกี่ยวข้องกับการใช้งาน ระบบส่งข้อมูลไปที่ใด และข้อจำกัดที่ผู้ใช้ต้องทราบก่อนใช้งาน

1. สถานะและขอบเขต

GovPrompt Thailand อยู่ระหว่าง Internal Pilot และยังไม่ใช่ระบบราชการทางการของหน่วยงานใด การนำไปใช้ในหน่วยงานจริงต้องผ่านการพิจารณาด้านอำนาจหน้าที่ นโยบายความมั่นคงปลอดภัย การคุ้มครองข้อมูลส่วนบุคคล และการอนุมัติที่เกี่ยวข้องของหน่วยงานนั้นก่อน

เอกสารนี้เป็นประกาศความโปร่งใสสำหรับระยะทดลอง ไม่ใช่คำรับรองว่าระบบปฏิบัติตามกฎหมายครบถ้วนทุกกรณี และต้องทบทวนอีกครั้งเมื่อขอบเขตผู้ใช้ ข้อมูล หรือผู้ให้บริการภายนอกเปลี่ยนแปลง

2. ข้อมูลที่ไม่ควรใส่ในระบบ

  • ข้อมูลลับของราชการ ข้อมูลด้านความมั่นคง รหัสผ่าน API key token secret หรือ private key
  • เลขบัตรประชาชน เลขบัญชี ข้อมูลสุขภาพ HN/AN ที่อยู่ เบอร์โทรศัพท์ หรือข้อมูลส่วนบุคคลจริงที่ไม่จำเป็น
  • เอกสารจริงที่ยังไม่ปกปิดชื่อ เลขประจำตัว หรือข้อมูลที่สามารถระบุตัวบุคคลได้

3. ข้อมูลที่เกี่ยวข้องกับการใช้งาน

ในหน้า Home ผู้ใช้อาจพิมพ์คำถาม เลือกไฟล์แนบ หรือใช้ฟังก์ชันค้นข้อมูลราชการสด ระบบถูกออกแบบให้ลดการส่งข้อมูลออกภายนอกเท่าที่จำเป็น โดยชื่อไฟล์จะถูกปกปิดก่อนนำไปประกอบ Prompt และ File object ถูกเก็บเพียงชั่วคราวในหน่วยความจำของหน้าเว็บในระหว่างการใช้งาน

ประวัติคำถามบนหน้า Home ถูกเก็บในหน่วยความจำของแท็บปัจจุบันและหายไปเมื่อโหลดหรือปิดหน้าใหม่ตามการออกแบบปัจจุบัน

4. การค้นข้อมูลราชการสดและผู้ให้บริการภายนอก

เมื่อใช้การค้นสด ข้อความค้นจะผ่าน Privacy Guard ที่หน้าเว็บก่อน แล้วส่งไปยัง Cloudflare Worker ของโครงการ จากนั้น Worker ตรวจข้อมูลเสี่ยงซ้ำอีกชั้นก่อนส่งคำค้นที่ผ่านการตรวจไปยังผู้ให้บริการค้นเว็บ Tavily เพื่อค้นเฉพาะโดเมนราชการที่กำหนดไว้

  • Worker ไม่ควรบันทึกข้อความคำค้นเต็มลง application log ตาม source code ปัจจุบัน แต่ใช้ metadata เช่น request ID ความยาวคำค้น จำนวนแหล่ง และระยะเวลาการทำงาน
  • ผลตอบกลับไม่ echo ข้อความคำค้นกลับมา
  • Tavily ถูกเรียกโดยตั้งค่าไม่ให้สร้าง answer และไม่ให้ส่ง raw content กลับ
  • การใช้ผู้ให้บริการภายนอกยังถือเป็น external processing จึงต้องหลีกเลี่ยงข้อมูลจริงที่ไม่จำเป็นแม้มีตัวกรอง

5. การส่งต่อไป ChatGPT

GovPrompt ไม่ส่ง Prompt ไป ChatGPT โดย API จากหน้า Home โดยอัตโนมัติ ปุ่ม “เปิดใน ChatGPT” จะเปิดเว็บไซต์ ChatGPT และพยายามคัดลอก Prompt ที่ผ่านการตรวจ/ปกปิดข้อมูลก่อน ผู้ใช้เป็นผู้วางข้อความหรือแนบเอกสารกับบริการภายนอกด้วยตนเอง

เมื่อผู้ใช้นำข้อมูลไปใช้กับบริการภายนอก ข้อมูลนั้นอยู่ภายใต้นโยบายและเงื่อนไขของบริการภายนอกดังกล่าว รวมทั้งนโยบายของหน่วยงานผู้ใช้ด้วย

6. วัตถุประสงค์ของการประมวลผลในระยะทดลอง

วัตถุประสงค์ของ GovPrompt ในระยะ Internal Pilot คือช่วยจัดโครงคำถาม ค้นแหล่งราชการ วิเคราะห์เบื้องต้น และจัดทำร่างงานเพื่อให้เจ้าหน้าที่ตรวจสอบต่อ ระบบไม่ได้ถูกออกแบบให้เป็นฐานทะเบียนประชาชน ระบบจัดเก็บเอกสารลับ หรือระบบอนุมัติอัตโนมัติ

7. การเก็บรักษาและความมั่นคงปลอดภัย

หลักการปัจจุบันคือ Data Minimization, Defense in Depth และ Fail Closed โดยลดข้อมูลที่ออกจาก browser ตรวจข้อมูลเสี่ยงทั้งฝั่งหน้าเว็บและ Worker จำกัด Origin/Method/request size ใช้ rate limiting ปิดการ echo query และลดระดับ observability/logging ของ Worker

อย่างไรก็ตาม Regex/DLP ไม่สามารถรับประกันการตรวจจับข้อมูลส่วนบุคคลได้ทุกชนิด ผู้ใช้ยังต้องปกปิดข้อมูลก่อนใช้งาน และไม่ควรใช้ GovPrompt เป็นที่เก็บเอกสารหรือข้อมูลสำคัญระยะยาว

8. สิทธิและช่องทางติดต่อ

หากผู้ใช้หรือเจ้าของข้อมูลมีคำถามเกี่ยวกับข้อมูลที่เกี่ยวข้องกับ GovPrompt หรือพบเหตุด้านความเป็นส่วนตัว/ความปลอดภัย สามารถติดต่อผู้ดูแลโครงการเพื่อให้ตรวจสอบและดำเนินการตามขอบเขตที่ระบบควบคุมได้

ประกาศนี้ต้องได้รับการทบทวนเมื่อ GovPrompt เริ่มรับผู้ใช้ภายนอก ใช้ข้อมูลจริงในวงกว้าง อ่านเนื้อหาไฟล์ เพิ่มบัญชีผู้ใช้/โปรไฟล์ เพิ่มฐานข้อมูล หรือเปลี่ยนผู้ให้บริการภายนอก โดยควรให้ DPO/ฝ่ายกฎหมาย/ผู้รับผิดชอบด้านความมั่นคงปลอดภัยของหน่วยงานที่นำไปใช้ตรวจทานก่อนใช้งานจริง
