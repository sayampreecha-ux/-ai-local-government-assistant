GovPrompt Thailandความโปร่งใสและความปลอดภัย

PRIVACY NOTICE · PUBLIC BETA

ประกาศความเป็นส่วนตัว

อธิบายการไหลของข้อมูลและมาตรการลดความเสี่ยงของ GovPrompt Thailand สำหรับการเปิดใช้งานฟรีแก่เจ้าหน้าที่ภาครัฐและผู้สนใจทั่วไป

1. สถานะบริการ

GovPrompt Thailand เป็นโครงการอิสระเพื่อช่วยค้น วิเคราะห์ และจัดทำร่างงานราชการ ไม่ใช่ระบบราชการทางการ ไม่ใช่คำวินิจฉัยของหน่วยงานรัฐ และไม่แทนผู้มีอำนาจอนุมัติ ลงนาม สั่งจ่าย หรือตัดสินใจตามกฎหมาย

2. ข้อมูลที่ไม่ควรกรอกหรือแนบ

หลีกเลี่ยงข้อมูลลับของราชการ รหัสผ่าน/API key/token/private key เลขบัตรประชาชน เลขบัญชี ที่อยู่ เบอร์โทรศัพท์ ข้อมูลผู้ป่วย ข้อมูลสุขภาพ ข้อมูลอ่อนไหว และข้อมูลส่วนบุคคลจริงที่ไม่จำเป็นต่อคำถาม หากต้องใช้เอกสารจริงควรปกปิดข้อมูลก่อน

3. Privacy Gate ก่อนประมวลผล

ช่องถามหลักใช้ Privacy Guard ก่อน routing การค้น และการสร้าง Prompt ระบบพยายามตรวจและปกปิดตัวระบุทั่วไป เช่น เลขประจำตัว อีเมล โทรศัพท์ เลขบัญชี ชื่อบุคคล รหัสผู้ป่วย วันเกิด ที่อยู่ และชื่อไฟล์แนบ พร้อมหยุดการส่งออกเมื่อยังพบข้อมูลเสี่ยงสูงหรือข้อมูลรับรองสิทธิ์ อย่างไรก็ตามการตรวจด้วยกฎอัตโนมัติไม่สามารถรับประกันการตรวจจับได้ทุกกรณี

4. การค้นข้อมูลราชการภายนอก

เมื่อคำถามจำเป็นต้องค้นข้อมูลปัจจุบัน คำค้นที่ผ่าน Privacy Guard จะถูกส่งไปยัง Cloudflare Worker ของโครงการ และ Worker ตรวจความเสี่ยงซ้ำก่อนเรียกผู้ให้บริการค้นเว็บภายนอกเพื่อค้นแหล่งราชการที่กำหนดไว้ การใช้บริการค้นภายนอกจึงถือเป็น external processing และไม่ควรมีข้อมูลส่วนบุคคลจริงที่ไม่จำเป็น

ตามการออกแบบปัจจุบัน Worker ไม่ควรบันทึกข้อความคำค้นเต็มเป็น application log และผลตอบกลับไม่ echo คำค้นกลับ ผู้ให้บริการค้นอาจเปลี่ยนแปลงได้ตามการพัฒนาระบบ จึงยึดหลักส่งเฉพาะคำค้นที่ลดข้อมูลแล้ว

5. ChatGPT, Gemini และบริการ AI ภายนอก

GovPrompt ไม่ส่ง Prompt ไปยัง ChatGPT หรือ Gemini โดยอัตโนมัติ ปุ่มเปิดบริการภายนอกทำหน้าที่คัดลอก Prompt ที่ผ่านการตรวจและเปิดเว็บไซต์ปลายทาง ผู้ใช้เป็นผู้ตัดสินใจวางข้อความหรือแนบเอกสารด้วยตนเอง หลังจากส่งข้อมูลให้บริการภายนอก การประมวลผลอยู่ภายใต้นโยบายของบริการนั้นและนโยบายของหน่วยงานผู้ใช้

6. ไฟล์แนบและประวัติการใช้งาน

หน้า Home ใช้ข้อมูลไฟล์เพื่อ workflow ในระหว่างการใช้งานและปกปิดชื่อไฟล์ก่อนนำไปประกอบ Prompt ไม่ควรใช้ GovPrompt เป็นคลังเก็บเอกสารหรือฐานข้อมูลบุคคล ประวัติการสนทนาในหน้าเว็บถูกออกแบบให้เป็นสถานะฝั่งผู้ใช้เพื่อการใช้งาน ไม่ใช่คลัง raw prompt ส่วนกลางของโครงการ

7. Analytics และการติดตาม

Public Beta ไม่ฝังตัวนับผู้เข้าชมจากบุคคลที่สามหรือ advertising/behavioral tracking pixel บนหน้า Home การวัดผลที่จำเป็นในอนาคตต้องยึดหลัก data minimization และต้องทบทวนประกาศนี้ก่อนเปิดใช้

8. หลักการรักษาความปลอดภัย

ระบบใช้แนวทาง Data Minimization, Defense in Depth, Fail Closed, จำกัด origin/method/request size, rate limiting, no-query-echo และ Human Review งานที่มีผลทางกฎหมาย การเงิน พัสดุ บุคคล หรือสิทธิของบุคคลต้องตรวจต้นฉบับและผู้มีอำนาจก่อนนำไปใช้จริง

10. การทบทวน

ประกาศนี้ต้องทบทวนเมื่อมีการเปลี่ยนผู้ให้บริการภายนอก เพิ่ม telemetry/analytics เพิ่มการอ่านเนื้อหาไฟล์หรือการเก็บข้อมูลส่วนกลาง เปลี่ยนกลุ่มผู้ใช้ หรือเปลี่ยนวัตถุประสงค์การประมวลผลอย่างมีสาระสำคัญ
