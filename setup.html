# GovPrompt Thailand Enterprise 4.2.1 — GP001 Pilot วันที่จัดทำ: 23 กรกฎาคม 2569 ## สิ่งที่เปลี่ยนแปลง - เริ่มปรับคลังเครื่องมือใหม่จากรหัส `GP001` - เปลี่ยนชื่อเครื่องมือเดิม `official-letter` เป็น `GP001 — AI ผู้ช่วยร่างหนังสือราชการ` - เพิ่มช่องกรอกประเภทหนังสือราชการ - GP001 สร้าง “Prompt พร้อมคัดลอก” จากแม่แบบที่กำหนดไว้ ไม่เรียก OpenAI API - GP001 รุ่นทดลองไม่หักจำนวนครั้งใช้งาน แต่ยังตรวจสิทธิ์สมาชิกและใส่ลายน้ำผู้ซื้อ - เครื่องมืออีก 9 รายการยังคงเป็นเครื่องมือเดิมและติดสถานะ “รอตรวจ” - ปรับหน้าแรกและพื้นที่สมาชิกให้แยก GP001 ที่ตรวจใหม่ออกจากเครื่องมือเดิมอย่างชัดเจน ## การคุ้มครองต้นฉบับ Prompt ฉบับเต็มของ GP001 อยู่ในฟังก์ชันฝั่งเซิร์ฟเวอร์ ไม่ได้ฝังไว้ใน `app.js` ฝั่งผู้เข้าชมทั่วไป ผู้มีรหัสใช้งานเท่านั้นจึงจะสั่งให้ระบบประกอบ Prompt ได้ ## ผลการตรวจ - JavaScript syntax check: ผ่าน - Automated tests: ผ่าน 12 รายการ - Preflight structure check: ผ่าน - Vercel Drop package check: ผ่าน
